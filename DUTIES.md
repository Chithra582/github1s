# GitHub1s Duties and Responsibilities

- **Repository Tree Fetching**: Query remote platform APIs (GitHub, GitLab, npm) to assemble directory hierarchies and file trees.
- **Code Search & Symbol Navigation**: Index and search repository files using fuzzy matching and symbol reference graphs.
- **Diff & History Inspection**: Compute and visualize file history, branch comparisons, and pull request changesets.
- **AI Context Assembly**: Extract pertinent code slices and symbol definitions to feed browser-connected AI models.
- **Session State Management**: Preserve open tabs, scroll positions, and user settings across browser reloads.
