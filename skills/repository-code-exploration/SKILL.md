# Repository Code Exploration Skill

Enables instant exploration of remote source code without local cloning.

## Core Capabilities
- Assembles virtual file systems from GitHub, GitLab, and npm APIs.
- Mounts directory trees and renders file contents on demand.
- Supports switching branches, tags, and commits instantaneously.
